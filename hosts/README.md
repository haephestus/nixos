# hosts

Per-machine host configurations. Each host is wired into `flake.nix`
(`nixosConfigurations.<name>`).

## laptop

The `harbinger` machine — a NixOS laptop (Intel CPU, NVIDIA GTX 1050 / 3GB VRAM).

| File | Purpose |
|---|---|
| `configuration.nix` | System-level config for the laptop |
| `hardware-configuration.nix` | Auto-generated by `nixos-generate-config` — **do not edit** |

### What `configuration.nix` does

- **Boot**: systemd-boot + EFI, `nix-ld`, distrobox (podman), flake support
  (`experimental-features = ["nix-command" "flakes"]`).
- **Desktop**: GNOME (imported from `modules/desktop/gnome.nix`), NVIDIA
  proprietary driver `legacy_580` (imported from `modules/desktop/nvidia.nix`).
- **AI**: Ollama as a systemd service with the CUDA build (`ollama-cuda`),
  tuned for a 3GB GPU (`OLLAMA_GPU_OVERHEAD`, flash attention, q8_0 KV cache,
  `MemoryHigh=9G`/`MemoryMax=11G`); `opencode` + `jq` installed via
  `modules/ai/coding-agents.nix`.
- **Drawing tablet**: OpenTabletDriver, Weylus (`uinput` group + udev rule),
  and a NetworkManager "weylus-hotspot" AP profile.
- **Audio / printing / memory**: PipeWire, CUPS, `zramSwap.enable`,
  `vm.swappiness = 10`.
- **User**: `harbinger` (wheel, networkmanager, uinput, input), zsh default shell.
- **Misc**: timezone `Africa/Johannesburg`, locale `en_ZA.UTF-8`, Nerd Fonts
  (departure-mono, fira-code), and system packages (gh, git, neovim, ghostty,
  zellij, brave, prismlauncher, android-tools, `nix-sweep`, home-manager, …).

### Notes / caveats

- The Weylus hotspot PSK (`somepassword123`) is hardcoded — move to sops once
  `modules/security/sops.nix` is wired in.
- Only a subset of `modules/` is imported here; the rest are staged (see
  [modules/](../modules/README.md)).
